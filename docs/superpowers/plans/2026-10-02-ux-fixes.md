## Corrections to the spec (FD)
- **FD1, SET-02:** device-code tokens store NO client name (`apps/server/src/mcp/token-store.ts`; only OAuth hosted connections carry one, `apps/server/src/mcp/oauth-store.ts:26`). Without a server change, token rows show **"Assistant connected with a token"** + "Created <date> · last used <date>" and **"Revoke this token"**. Hosted rows show `<clientName> (<host>)` and **"Disconnect <clientName>"**. Naming device-code clients is deferred (it needs the device flow to ask for a name).
- **FD2, U1 boundaries:** U1 applies to SELECTION indicators, so the settings rail, Help contents, the current tab, a chosen segment, and a pressed filter chip / include choice all move to track + weight (+ a check icon for chips). **Switches keep the accent for "on"**, because a switch's on-state is the control's value (the platform convention), not a navigation selection. Calendar item bars move to `fillPrimary` with an accent edge (SYS-04 decoration).
- **FD3, U3 and the bottom bar:** the bar's visibility gets its OWN query, `TABLET_BAR_QUERY = '(max-width: 64rem)'`. It does NOT widen `PHONE_QUERY` (`apps/web/src/use-is-phone.ts:10`), which also drives the phone top bar and every phone-only rule. Cases 21.033, 21.028 and the manual case 21.231 (Duo unfolded 890 "no bottom bar") are amended deliberately, saying so.
- **FD4, the 24px gutter:** `.gn-shell` is `padding: 0 1.25rem` (20px, globals 166) and 0.75rem ≤60rem (168–170). Both become 1.5rem. `.gn-nav__inner` (≤60rem `padding-inline: 0.75rem`) and the sign-in phone arm follow.
- **FD5, BRD-03 wording:** `formatStateProvenance` (`packages/app-core/src/provenance.ts:121`) is shared with the sheet's State row and My Work. Change the card's use only: a new `formatCardProvenance` returns "Moved to In progress by Kiro on 30 Sep". The sheet's "marked … by … on …" stays.
- **FD6, NP-05:** contested attention items merge on the CLIENT (`packages/app-core/src/online/mappers.ts:2516-2566`), so the cap and the per-ticket de-duplication happen in the client (`attention-strip.tsx`), after the merge. The server is unchanged.
- **FD7, BRD-09:** the shared `Dialog` (`packages/ui/src/components/dialog.tsx:61`) has no footer slot. Add a `footer?: ReactNode` prop, rendered OUTSIDE the scrolling `.gn-dialog__body` (ui.css 948) and sticky at the bottom. NewTicketDialog's actions move into it.
- **FD8, nothing to reuse:** there's no scroll-fade utility, no type-size tokens, no canvas Fit control and no timeline today line. Each is created in its owning task.
