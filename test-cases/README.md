# test-cases — gisik-nokma

Human-readable catalogue of every scenario worth covering, one file per top-level feature bucket, mirroring `Features.md` section numbering.

Status markers: `❌` not covered · `✅` covered · `🟡` partial · `🧪` manual · `🚫` consciously out of scope (with reason)

Rules: never renumber existing IDs; flip status in the same commit as the covering test; cross-reference tests by case ID; prose only — no test code here.

**The cross-reference rule above is now checked, not just stated (Lane F Pass 1, `scripts/check-case-citations.mjs`, `pnpm check:citations`, its own CI job).** A `✅` case must have its id appear literally — as a test name or a comment — in some test/e2e file. This closes the gap the coordination doc recorded by name (2026-08-31): "no test in the repo cites a case id... a test can be deleted and its case keeps its ✅." Measured: 1525 checked ids repo-wide, 710 already cited, 815 not — the convention line above long predates anyone actually following it at scale. (A first pass under-measured this at 1470/663/807; review caught a real extraction bug — range-form ids like `- **3.89–3.94** ✅ ...` were silently dropped from the check entirely — fixed before this line was written, not after.) Rather than block on a repo-wide backfill, the check runs as a **ratchet**: a committed per-file ceiling (`scripts/fixtures/check-case-citations-baseline.json`) that must equal the real uncited count EXACTLY — higher than reality means the ratchet is stale and must be tightened; lower means something regressed (a citing test was deleted, or a new ✅ case shipped without one) and the check fails, naming the exact ids. Backfilling an existing file's citations is real, per-file work, carried with a named owner in the PR/handoff that introduced this check rather than restated here (ownership is a moment-in-time fact this index would only get stale about); a NEW ✅ case anywhere should be cited from the day it is written, which costs nothing extra and keeps that file's ceiling from ever needing to move.
